# Signaler une faille de sécurité

Merci de **ne pas ouvrir d’issue publique** pour une faille.

Utilise le signalement privé de GitHub : onglet **Security** de ce dépôt, puis **Report a vulnerability**. Indique le
fichier et la fonction concernés, le scénario d’attaque et, si possible, une preuve de concept qui n’utilise que des
clés et des comptes de test.

Sont particulièrement attendus les signalements qui permettraient :

- d’obtenir une signature MetaMask autre que celles décrites dans le README, ou d’en détourner une ;
- de lire ou d’exfiltrer la clé de l’agent de trading ;
- de faire passer un ordre que l’utilisateur n’a pas confirmé, ou sur un autre actif que celui affiché ;
- de prélever un frais d’interface supérieur à celui affiché et signé.

Une réponse est donnée sous 7 jours. Ce dépôt ne propose pas de prime aux bogues.

---

**Reporting a vulnerability** — please do not open a public issue. Use GitHub private vulnerability reporting
(_Security_ tab → _Report a vulnerability_). We aim to reply within 7 days. No bug bounty is offered.
